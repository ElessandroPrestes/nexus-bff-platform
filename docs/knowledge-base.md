# Base de Conhecimento

A base de conhecimento registra contexto durável do projeto em `knowledge/`.

## O que registrar

- Glossário e linguagem ubíqua.
- Integrações e contratos externos.
- Restrições de negócio e compliance.
- Decisões recorrentes e armadilhas conhecidas.
- Runbooks operacionais.

## O que não registrar

- Segredos e credenciais.
- Decisões efêmeras de sessão.
- Requisitos não aprovados.

## Estrutura sugerida

```
knowledge/
├── glossary.md
├── integrations.md
├── constraints.md
└── runbooks/
```
