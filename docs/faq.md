# FAQ

**Posso implementar sem SPEC?**
Não. Toda implementação começa por uma SPEC aprovada.

**A IA pode aprovar uma SPEC?**
Não. A IA redige; a aprovação é humana.

**E se eu encontrar divergência entre SPEC, `PROJECT.md` e código?**
Registre como defeito, mudança de escopo ou dívida documental. Não resolva silenciosamente.

**Preciso de ADR para tudo?**
Só para mudanças arquiteturais.

**Onde registro evidências de teste?**
Em `reviews/` e na TASK, conforme `standards/testing.md`.

**Como começo uma funcionalidade?**
Siga `workflows/feature.md`.

**Posso mudar a stack?**
Sim, com ADR e atualização do `PROJECT.md`.

**O framework exige uma linguagem?**
Não. É independente de linguagem, framework e provedor de IA.
