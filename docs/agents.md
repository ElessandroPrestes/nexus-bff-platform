# Papéis e Responsabilidades dos Agentes

Cada papel tem missão, responsabilidades e limites definidos em `agents/`. Um agente de IA pode executar um papel, mas **nunca** aprova em nome de uma pessoa.

| Papel | Arquivo | Missão |
| --- | --- | --- |
| Product Discovery | `agents/product-discovery.md` | Entender problema, usuários e restrições |
| Architect | `agents/architect.md` | Definir e registrar arquitetura |
| UX Designer | `agents/ux-designer.md` | Discovery de UX e design de interface |
| Spec Author | `agents/spec-author.md` | Redigir SPECs e TASKs |
| Implementer | `agents/implementer.md` | Implementar escopo aprovado |
| QA Engineer | `agents/qa-engineer.md` | Testar e produzir evidências |
| Reviewer | `agents/reviewer.md` | Design review e code review |
| Documenter | `agents/documenter.md` | Manter documentação e `PROJECT.md` |

## Regras gerais

- Todo papel lê `AGENTS.md` antes de agir.
- Aprovações são humanas e registradas.
- Conflitos de papel são resolvidos pela governança (`docs/governance.md`).
