# Governança

## Princípios

1. Aprovações são humanas.
2. A IA redige, propõe e implementa; nunca aprova.
3. Divergências são registradas, nunca silenciadas.
4. Mudanças de escopo exigem revisão explícita.

## Autoridade

| Decisão | Quem aprova |
| --- | --- |
| SPEC | Pessoa responsável pelo produto/técnica |
| Design | Pessoa responsável por UX/UI |
| ADR | Pessoa responsável por arquitetura |
| Release | Mantenedores |

## Registro

- Aprovações são registradas na própria SPEC/ADR (campo de aprovação).
- Reviews ficam em `reviews/`.
- Decisões arquiteturais ficam em `adr/`.

## Exceções

Exceções a quality gates exigem registro explícito com justificativa, dono e prazo de resolução.
