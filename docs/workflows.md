# Fluxos Oficiais

## Feature

Fluxo completo em `workflows/feature.md`.

## Correção (fix)

1. Registrar defeito (issue ou `PROJECT.md`).
2. Se mudar comportamento, atualizar/abrir SPEC.
3. Criar TASK `fix/*`.
4. Implementar, testar, revisar.
5. Registrar evidências.

## Decisão arquitetural

1. Abrir ADR em `adr/`.
2. Revisar alternativas e consequências.
3. Aprovar.
4. Atualizar `PROJECT.md`.

## Documentação

1. Identificar documento afetado.
2. Atualizar mantendo consistência com código e SPEC.
3. Revisar.

## Release

1. Quality gates satisfeitos (`standards/quality-gates.md`).
2. `CHANGELOG.md` atualizado.
3. `PROJECT.md` refletindo o estado.
4. Tag semântica.
