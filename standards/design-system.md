# Standard — Design System

## Objetivo

Definir tokens, componentes e governança visual para manter consistência.

## Tokens

| Categoria | Exemplos |
| --- | --- |
| Cor | primária, secundária, superfície, texto, feedback |
| Tipografia | família, escala, pesos, line-height |
| Espaçamento | escala base (4/8), insets, gaps |
| Raio | cantos por componente |
| Sombra/elevação | níveis |
| Movimento | duração, easing |

> Os valores concretos serão definidos quando a identidade visual for aprovada. Não inventar.

## Componentes

- Cada componente tem estado, variantes e regras de uso.
- Componentes novos exigem justificativa e revisão.
- Componentes devem seguir acessibilidade.

## Governança

- Mudanças em tokens são versionadas.
- Componentes quebrados seguem política de depreciação.
- O design system é fonte de verdade visual.
